# Automated Employee Onboarding & Offboarding System (ServiceNow)

## Overview
A ServiceNow solution to automate the complete employee lifecycle —
onboarding and offboarding — using Service Catalog items, Flow Designer
workflows, role-based ACLs, and SLA dashboards.

## Business Objectives
1. Streamline employee lifecycle management
2. Enhance HR and manager efficiency
3. Ensure secure role-based access
4. Enable data-driven HR decisions
5. Support organizational compliance & sustainability

## Functional Scope
- Onboarding & Offboarding Service Catalog items
- Dynamic variable handling
- Flow Designer workflows for approvals & task assignment
- Departmental task routing: HR, IT, Facilities, Security
- Role-based ACLs
- Dashboards & reports (SLA tracking, completion rates)

## Stakeholders
HR | Managers | IT | Facilities | Security

## Roadmap
Catalog Creation → Table Setup → Flow Designer Automation →
SLA Configuration → Testing → Deployment
